# BDM Capstone Project

A Business Data Management capstone project focused on applying data analysis and predictive techniques to solve practical business problems.

## Problem Statement

The project focuses on addressing three key areas:

- Customer segmentation based on purchasing behavior
- Demand forecasting and inventory optimization
- Product-wise profitability and margin analysis

## Objectives

- Analyze historical sales and customer data
- Identify meaningful customer segments using RFM analysis
- Analyze product demand and sales patterns
- Forecast future demand using time-series models
- Classify products based on demand using ABC analysis
- Analyze product-level profitability
- Evaluate the impact of pricing and cost scenarios

## Methodology

The project follows the following workflow:

1. Data Collection
2. Data Cleaning and Preprocessing
3. Exploratory Data Analysis
4. Customer Segmentation
5. Product Demand Analysis
6. Demand Forecasting
7. ABC Classification
8. Profitability Analysis
9. Scenario Modeling
10. Visualization and Interpretation

## Techniques Used

- RFM Analysis
- ABC Classification
- Time Series Forecasting
- SARIMA
- Holt Linear Trend
- Profitability Analysis
- Scenario Modeling
- Exploratory Data Analysis
